Hack or Myth?
This is a quick True or False quiz app for Android, made with Kotlin in Android studio. This app is there to test how much you really know about everyday tech.

Front Page of the application:

The main purpose of this application is to help the users with everyday tech advice that gets passed around and is half remembered or just wrong, Such as, private browsing, which many people believe that it hides you from your internet provider, which is not true as it only stops the browser from saving stuff on your device. Hack or Myth helps clear up information like such, you simply read short statements, decide if it's true or not, then you get your result on the spot. After each answer, the app explains why, so you learn something even though you guessed wrong. The app is meant to be relaxed, hence there is no timer that's timing you. You go at your own pace.
